# llm-router-axi

- Routing doctrine belongs in the [bundled policy seed](src/policy.default.json) and the user's policy, never hard-coded harness/model/lane/provider/pool choices in `src/`. [Design](docs/design.md) owns semantics. Preserve pinned Firstmate selector parity and byte-identical frozen refusal diagnostics: `route` uses declared chain ranks; `select` retains legacy rotation. In [parity tests](test/parity/selector-parity.test.ts), resolve temporary homes with `realpathSync` before hashing; macOS `/var` aliases otherwise change tied winners.
- Spawn, suite and local-LLM admission are different purposes. Never move suite/llama occupancy refusals into spawn. Bare purpose checks fail closed. Explicit override reuses eligibility and spawn-capacity checks, including its suggested alternative, without rotating LRU. A force-override audit is credential-free; its existence grants no permission to bypass a refusal. Read [capacity](src/capacity.ts) before admission changes.
- Jev classification/triage/pick remain advisory and never influence live `route`/`select`. Keep task classification separate from depletion detection; triage must not contradict depletion or mutate routing/cooldown/record state. `pick` must not imply capacity/reserve/cooldown admission. The TypeSafe key is environment-only (`TYPESAFE_API_KEY`), never a flag, output, error, log or fixture value; preserve sentinel tests in [Jev regressions](test/jev.test.ts) and [slice-2 regressions](test/jev-slice2.test.ts).
- 429 evidence opens cooldown immediately with `suspect: true` and doubled reserve until fresh non-429 evidence clears it. Keep additive cooldown evidence separate from frozen skip strings. Unknown Go-pool semantics and model-prefix/provider matching stay fail-closed; inspect [usage integration](src/usage.ts), never infer price from arbitrary windows.
- [Schema source](src/policy/schema.ts) owns generated `policy.schema.json`; unknown keys and unresolved references must fail validation. The runtime seed is copied into `dist` and read by the existing loader, not imported as JSON. The [live-policy fixture](test/fixtures/policy/live-mac-mini.policy.json) is sanitized routing doctrine only, never credentials; refresh only for legitimate shape changes.
- Machine fixtures must disable live llama-slot probing with `LLM_ROUTER_LLAMA_SLOTS_URL=off`, or supply the exact busy-count seam, and include all four `llama*` keys. An omitted fixture key can fall through to a real network probe. [Suite setup](test/setup.ts) owns the default; fixture verification needs no live endpoint.
- Worker count means invocation roots: collapse matching descendants and exclude Cursor worker daemons. Vendored usage-axi process snapshots and golden counts own parity; `roots[]` remains audit evidence. Do not import an absent usage-axi library export or edit Firstmate to conceal drift. See [machine fixture guidance](test/fixtures/machine/README.md).
- Preserve the leaf-clean version fast path and command-specific errors/exits: validation errors are 2; route/capacity refusals are structured exit 1; `select` remains compact launch JSON with frozen diagnostics on stderr and exit 3. Unknown flags must fail explicitly. Source/CLI own exact flags and timeouts; portable development must not require a private coordinator home.

[package.json](package.json) owns commands. Keep generated policy schema, copied runtime assets and [skill source](src/skill.ts) synchronized; generated skill output is not independently authored guidance.
